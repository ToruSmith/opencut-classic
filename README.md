# OpenCut（精簡網頁版）

在瀏覽器裡剪輯影片的工具，**檔案只在你的電腦上處理，不會上傳**。

這是 [OpenCut](https://github.com/opencut-app/opencut-classic) 舊版（已封存）的精簡分支：
去掉網站、帳號、資料庫與後端，只保留編輯器本體，並把 Next.js 換成 Vite，
建置後是一包純靜態檔案，放在任何靜態主機（GitHub Pages 等）都能執行。

## 已有的功能

- 多軌時間軸、分割、拖放排序、變速
- 關鍵影格與貝茲曲線編輯器（位置、縮放、旋轉、不透明度、音量、效果參數等）
- 遮罩（含自由繪製與羽化）、混合模式
- 文字、貼圖、字幕與語音轉文字（在瀏覽器內執行）
- 逐幀離線匯出（MP4 / WebM），不需即時錄製
- 專案儲存在瀏覽器本機（IndexedDB / OPFS）

## 使用

網址：`https://<你的帳號>.github.io/opencut-classic/`

## 常用快捷鍵

| 按鍵 | 功能 |
|---|---|
| Space / K | 播放、暫停 |
| J / L | 後退、前進 1 秒 |
| ← / → | 上一格、下一格 |
| ↑ / ↓ | 上一個、下一個剪輯點 |
| S | 在播放頭分割 |
| Q / W | 分割並刪除左側 / 右側 |
| Delete | 刪除 |
| Shift+Delete | 波紋刪除(刪除並補上空隙) |
| Ctrl+X / C / V | 剪下、複製、貼上 |
| M | 在播放頭加上 / 移除書籤 |
| Shift+↑ / Shift+↓ | 上一個、下一個書籤 |
| = / - | 放大、縮小時間軸 |
| N | 切換吸附 |

完整清單與自訂在編輯器的「鍵盤快速鍵」視窗。

## 瀏覽器需求

需要較新的桌面瀏覽器（Chrome、Edge、Firefox、Safari），並支援 WebCodecs。
渲染優先使用 WebGPU，不支援時退回 WebGL。

## 本機開發

```bash
bun install
cd apps/web
bun run dev        # http://localhost:3000
bun run build      # 輸出到 apps/web/dist
bun run typecheck
```

## 目前的限制

- 效果庫:模糊、去背(色度鍵)、色彩調整、色調、黑白、復古褐色、暗角、銳利化、發光、分離色調,以及暖色/冷色/褪色底片風格。還不支援套用 LUT(.cube)檔。
- 轉場:單一片段的進場 / 出場動畫,以及兩段之間的「交叉溶解」。交叉溶解需要把後一段放在另一條軌道、和前一段重疊(同一條軌道上的片段不能重疊)。
- 沒有直接串流寫入硬碟的瀏覽器（非 Chrome / Edge）匯出時，影片會先放在記憶體。音訊已改為分段處理，不再隨長度整段載入。
- 「Sounds」音效搜尋分頁已移除（它依賴原本的後端服務）。

## 近期新增

- 繁體中文介面、Noto Sans TC 字型
- 濾鏡:色彩調整、黑白、復古褐色、暗角(自訂 GPU 著色器,由 GitHub Actions 編譯 WASM)
- 轉場面板:淡入、淡出、淡入淡出(以關鍵幀實作)
- 定格(freeze frame)、復原/重做按鈕
- 匯出直接串流寫入硬碟(Chrome / Edge)
- 專案備份檔(`.opencut-backup`)匯出與匯入
- 離線模式(預設關閉,可在「儲存空間」視窗開啟)
- 音訊淡入淡出:拖曳時間軸上音訊片段左上 / 右上角的圓點,或在屬性面板輸入秒數(影片的聲音也可以)
- 交叉溶解:兩段重疊的片段一鍵套用畫面溶接與聲音交叉淡化
- 新濾鏡:銳利化、發光、分離色調
- 版本紀錄:編輯時自動保存時間軸(每 10 分鐘、內容有變才存,最多 20 份),在專案列表的選單裡還原
- 備份提醒:專案超過 7 天沒有匯出備份會在卡片上提示
- 代理檔:素材面板影片右鍵「建立代理檔」,預覽改用低解析度版本,4K 或手機長片段拖曳時間軸更順;匯出仍用原始檔
