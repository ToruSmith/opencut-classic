# 實機驗收清單

CI 只能證明「程式能編譯、純邏輯的測試過了、shader 語法正確」。**畫面、聲音、效能、瀏覽器儲存**都沒有人在 CI 裡看過,
所以每次部署後,花 5 分鐘用真實瀏覽器走一遍。

## 準備(一次就好,存起來重複使用)

- 一支 10~20 秒、有人說話的影片(`talk.mp4`),最好是中文
- 一首短音樂(`music.mp3`)
- 一張圖片(`photo.jpg`)
- 一個綠幕短片(`green.mp4`,沒有可略過去背那項)
- 一個三則字幕的 `test.srt`

開啟網站後,按 F12 打開主控台,整個過程留著看。

## 1. 基本流程(每次都要做)

- [ ] 開啟網站,專案列表正常顯示,主控台沒有**新的**紅色錯誤
- [ ] 建立新專案,進入編輯器
- [ ] 「媒體」匯入 `talk.mp4`、`music.mp3`、`photo.jpg`,縮圖都出現
- [ ] 把影片拖進時間軸,預覽有畫面,按播放**有聲音**,畫面與聲音同步
- [ ] 拖動播放頭,預覽跟著更新,不會卡在同一格
- [ ] 分割、刪除片段,各做一次「復原」「重做」
- [ ] 重新整理頁面,再開同一個專案:內容、素材都還在

## 2. 效果(最近新增,優先看)

在「特效」分頁,把效果拖到影片上,調整屬性面板的滑桿,**預覽要即時變化**:

- [ ] 模糊
- [ ] 色彩調整、黑白、復古褐色、暗角
- [ ] **色溫與色調**:色溫往右畫面變暖、往左變冷;陰影、亮部、褪色有反應
- [ ] **暖色調 / 冷色調 / 底片褪色**:強度拉到 0 時畫面回到原樣
- [ ] **去背(綠幕)**:套在 `green.mp4` 上,綠色變透明,下層看得到;調「容許範圍」「邊緣柔化」邊緣有變化
- [ ] 同一個片段疊兩個效果,兩個都有作用
- [ ] 把效果刪掉,畫面恢復

> 任何一個 shader 壞掉,可能整個效果面板都沒反應(所有效果共用同一個管線)。如果全部效果一起失效,先看主控台。

## 3. 轉場與淡化(最近新增,優先看)

選取時間軸上的片段,到「轉場」分頁:

- [ ] 「淡入淡出」:影片開頭漸顯、結尾漸隱;**音量也跟著漸變**(戴耳機聽)
- [ ] 先把片段音量調成 −6 dB、不透明度調成 50%,再套淡入:淡入結束時應停在 −6 dB 和 50%,**不會跳回 0 dB / 100%**
- [ ] 進場:從左滑入、縮放進入、旋轉進入、彈出,各看一次
- [ ] 出場:切換到「片段結尾」,向右滑出、縮小退出,動畫結束時剛好是片段尾端
- [ ] 套用後在屬性面板或曲線編輯器看得到關鍵影格,可以微調
- [ ] 「復原」一次能撤銷整個轉場

## 3.5 新快捷鍵(最近新增,優先看)

- [ ] 時間軸有三四個片段時按 ↓ / ↑:播放頭一格一格跳到片段的頭尾;連按會一直往前/往後
- [ ] 選一個中間的片段按 Shift+Delete:片段消失,同軌後面的片段往前補上;Ctrl+Z 能完整還原
- [ ] 選片段按 Ctrl+X 再移動播放頭按 Ctrl+V:片段被搬到新位置
- [ ] 按 M:播放頭位置出現書籤,再按一次消失;有幾個書籤時按 Shift+↑ / Shift+↓ 會在書籤之間跳
- [ ] 按 = / -:時間軸放大、縮小
- [ ] 點一下右側屬性面板的滑桿後按 ↑ ↓:應該是調整滑桿,不是跳剪輯點
- [ ] 打開「鍵盤快速鍵」視窗:新項目都在,= 與 - 的標示正確(不是顯示成 +)

## 3.6 音訊淡化、交叉溶解、新濾鏡(最近新增,優先看)

- [ ] 時間軸上的音樂片段:滑過時左上 / 右上角出現白色圓點,往內拖曳出現三角形陰影與「淡入 x 秒」提示;放開後播放,開頭聲音漸大、結尾漸小
- [ ] 屬性面板「音訊」區有「淡入(秒)」「淡出(秒)」,改數字後時間軸的陰影同步變化;Ctrl+Z 能復原
- [ ] 有淡化的片段在中間按 S 分割:左半只剩淡入、右半只剩淡出,分割點沒有突然靜音
- [ ] 匯出一段有淡入淡出的影片,聽起來和預覽一致
- [ ] 把後一段影片拖到上方軌道、開頭和前一段重疊約 1 秒,選取其中一段 →「轉場」面板 →「交叉溶解」:重疊處畫面溶接、聲音交叉淡化;Ctrl+Z 一次就全部復原
- [ ] 效果面板有「銳利化」「發光」「分離色調」,套用後畫面有變化,拖動參數即時更新;匯出結果和預覽一致(發光範圍不會因為解析度不同而差很多)

## 3.7 版本紀錄、備份提醒、代理檔(最近新增,優先看)

- [ ] 編輯專案 10 分鐘以上(期間有修改)後回到專案列表,專案選單「版本紀錄」裡有一筆;按「還原」→「確定還原?」後內容回到那個版本,列表裡多了一筆「還原前」的版本
- [ ] 從編輯器用瀏覽器「上一頁」回到列表後還原,再打開專案,看到的是還原後的內容
- [ ] 專案選單「匯出備份」能下載 `.opencut-backup`;建立超過 7 天且沒備份的專案卡片上有「尚未備份」提示,備份後消失
- [ ] 素材面板對影片按右鍵「建立代理檔」:縮圖左下角顯示「代理 xx%」,完成後顯示「代理」;預覽拖曳時間軸明顯變順,畫面時間點和原本一致
- [ ] 建立代理檔途中按右鍵「取消建立代理檔」:進度消失,沒有錯誤
- [ ] 有代理檔的影片匯出:輸出是原始解析度(不是 1280)
- [ ] 右鍵「刪除代理檔」後預覽改回原始檔

## 3.8 專案儲存與備份(最近修正,優先看)

- [ ] 打開網站後,之前匯入過、打開是空白的專案能正常打開了;如果原本的專案被取代過,它也回到列表(名稱沒有「(匯入)」)
- [ ] 按「新專案」後什麼都不做就離開(選單「離開專案」或瀏覽器上一頁):首頁不會多一個專案,出現「空白專案沒有保留」
- [ ] 新專案只上傳素材、沒放到時間軸就離開:專案會保留
- [ ] 在網址列打一個不存在的 `#/editor/xxx`:顯示「找不到這個專案」,不會多出新專案
- [ ] 首頁有長度 0 的專案時出現「清除空白專案」,按下後只刪掉真正空白的
- [ ] 匯出備份 →「完整備份」→ 匯入:新專案的時間軸與素材都在
- [ ] 匯出備份 →「只存專案」→ 檔案很小 → 匯入:跳出「重新連結素材」,一次選好原始檔案後素材全部回來;打開專案畫面正常
- [ ] (Chrome / Edge)重新連結視窗按「選擇資料夾」,選放素材的資料夾(素材放在子資料夾裡也要能找到):顯示掃描進度,完成後素材全部對上;掃描中按「取消」會停止
- [ ] Firefox / Safari 沒有「選擇資料夾」按鈕,「選取檔案」照常可用
- [ ] 只存專案的匯入、但先按「稍後再說」:打開專案時上方出現「有 N 個素材找不到檔案」,按「重新連結素材」可以補

## 3.9 效果加速、風格化濾鏡(最近新增,優先看)

- [ ] 模糊:強度 0 → 100 拖動,畫面平順變化,沒有突然跳變或黑邊;強度很低時看起來和以前一樣
- [ ] 同一片段疊 3 個以上效果(模糊 + 發光 + 銳利化)播放,`window.__renderPerf = true` 的 `renderFrame` 不應比以前慢
- [ ] 馬賽克:方塊大小調整即時反映;預覽與匯出的方塊大小比例一致;片段邊緣沒有拉絲
- [ ] 色差:「由中心向外」時中央清楚、邊緣分出紅藍;切到「固定方向」才出現「方向角度」,調角度方向跟著轉
- [ ] 色調分離:色階 2 時接近海報效果,32 時幾乎和原圖一樣;透明的貼圖 / 文字邊緣不會變黑
- [ ] 主控台沒有 WGSL / shader 錯誤(任何一個 shader 壞掉,所有效果都會一起失效)

## 3.10 底片顆粒、LUT、遮罩羽化(最近新增,優先看)

- [ ] 底片顆粒:播放時顆粒會跳動、暫停時固定不動;「彩色顆粒」打開有彩色雜點;「暗部保留」調高時黑色區域較乾淨
- [ ] 底片顆粒:匯出的影片顆粒也會動(不是一張固定的雜訊貼在畫面上)
- [ ] LUT 調色:效果面板按「匯入 .cube 檔…」選一個 LUT(33 或 65 都試),畫面立即套用;強度 0 時和原圖相同
- [ ] 同一專案第二次加 LUT 效果時,下拉選單能選到剛才匯入的 LUT;選錯檔案(例如 .txt 改名)會出現中文錯誤訊息
- [ ] LUT 專案:重新整理頁面、匯出備份再匯入,LUT 仍然有效;匯出影片有套到 LUT
- [ ] 遮罩羽化:有羽化的遮罩播放順暢,邊緣柔化和以前一樣

## 3.11 內建 LUT 風格、動態效果(最近新增,優先看)

- [ ] 時間軸上的特效片段顯示中文名稱(包含之前已經放好的「Film-grain」「Lut」片段)
- [ ] LUT 調色:新加上去就有「青橙電影感」;下拉選「負片」時畫面變成像底片負片(黑變白、藍天變橘)——這代表 LUT 套用正確
- [ ] LUT 其他內建風格(褪色底片、日系清新、賽博夜景、高對比黑白)都能切換,強度 0 時和原圖相同
- [ ] 畫面震動:播放時畫面晃動、暫停時停在固定位置;「放大填滿」開著時不露出黑邊;改「換一種晃法」晃法不同
- [ ] 放射模糊:強度調高有往中心衝的速度感;改中心 X / Y 位置跟著移動
- [ ] 故障:播放時一陣一陣出現橫向錯位與紅藍分離;強度 0 時沒有效果
- [ ] 鏡像:左右 / 上下 / 四格都對稱;「保留另一半」換成另一邊
- [ ] 以上效果匯出後和預覽一致;主控台沒有 WGSL / shader 錯誤

## 3.12 刪除素材後復原(最近修正,優先看)

- [ ] 匯入一支影片放上時間軸 → 在素材面板刪除它 → 按復原:素材回到素材面板、時間軸上的片段回來,**能正常播放**(不是黑畫面或錯誤)
- [ ] 復原後再重做、再復原:都正常
- [ ] 匯入素材後馬上復原(素材消失)→ 重做:素材回來且能播放
- [ ] 刪除素材後**不復原**,重新整理頁面再開專案:素材不在了(不會又冒出來)
- [ ] 重新整理後瀏覽器的儲存空間用量有降下來(刪掉的大檔案在開啟專案時才會真正釋放)

## 3.13 效果組合(最近新增,優先看)
- [ ] 特效面板上方有「組合」卡片;點「衝擊」→ 時間軸在播放頭放入 3 個特效片段(0.5 秒),播放時有震動 + 放射模糊 + 色差
- [ ] 點「復古膠卷」→ 3 層(LUT、顆粒、暗角);畫面偏褪色有顆粒
- [ ] 一次「復原」就能整組移除,「重做」整組回來
- [ ] 連點同一組合兩次(同一位置)→ 第二組放到別的軌道,不重疊報錯

## 3.14 兩段之間的轉場(推移 / 滑動擦除 / 縮放)(最近新增,優先看)
- [ ] 兩段影片放在不同軌道、結尾與開頭重疊,選其中一段,轉場面板選方向後按「推移」→ 重疊期間兩段一起朝該方向移動,沒有露出黑邊以外的跳動
- [ ] 「滑動擦除」:後一段在上層 → 後一段滑進來蓋住;前一段在上層 → 前一段滑出去露出後一段
- [ ] 「縮放」:前一段放大、後一段由小放大,上層淡化;聲音有交叉淡化
- [ ] 一次「復原」整個轉場消失;兩段沒重疊時顯示提示而不是無反應

## 3.18 進度式擦除轉場(線性 / 光圈 / 時鐘 / 百葉窗 / 棋盤 / 菱形 / 溶解 / 方塊 / 對開)(最近新增,優先看)

**這項的 shader 只過了語法檢查,畫面完全沒有實測,請特別仔細看。** 準備:兩段影片放在不同軌道,後一段開頭和前一段結尾重疊 1 秒,選取其中一段,轉場面板「兩段之間的擦除」。

- [ ] **首尾最重要**:轉場開始前一格,上層畫面完全正常(沒有任何缺角、變淡);轉場結束後一格,上層完全消失、只剩下層(出場時);進場時相反(開頭完全看不到上層,結束時完整)。
- [ ] 線性擦除:方向選「→ 向右」,上層從左邊開始消失、邊界往右推進;分別試四個方向,邊界移動方向和箭頭一致;「硬邊 / 柔邊 / 很柔」邊界的模糊寬度明顯不同;「反向」讓掃描方向相反
- [ ] 圓形光圈:從畫面中心打開一個圓、越開越大,圓的邊緣是正圓(不是橢圓),最後剛好蓋滿四個角,角落沒有殘留
- [ ] 時鐘掃過:從 12 點鐘開始順時針掃一圈,轉場結束時沒有留下細縫;「反向」變逆時針;改特效屬性的「角度」可改變起點
- [ ] **新增的 6 種(2026-10-28,畫面未實測)**,每種都看「首尾」那一項:
  - 百葉窗:畫面切成 8 條,每條同時沿方向擦開;方向「↓」時是橫條;特效屬性的「數量」改條數
  - 棋盤:方格(不是長方形)交錯擦開,一半格子先擦、另一半在後半段才擦
  - 菱形:從中心打開菱形,最後剛好蓋到四個角
  - 噪點溶解:不規則的雲狀斑塊溶掉,硬邊像燒穿、柔邊像墨水暈開;「種子」改圖樣;**直式畫面斑塊不會被拉長**
  - 方塊崩落:方塊隨機一塊塊消失(「硬邊」最明顯),「種子」改順序
  - 對開:方向「→」時從垂直中線往左右打開,「↓」時從水平中線往上下打開
  - 卡拉 OK 填色(3.21)仍然由左向右填(它用的是「線性 + 反向」,反向的編號改了)
- [ ] 上層是後一段(進場)時,三種的前進方向和出場時一致(不是倒著掃)
- [ ] **預覽與匯出一致**:同一個轉場匯出後用播放器看,邊界位置、柔邊與預覽相同;不同畫布比例(直式 9:16)也正確
- [ ] 轉場以外的時間:播放順暢、畫面與沒加特效時相同(進度 0 不跑 pass)。對含擦除的專案開 `window.__renderPerf = true`,比較轉場前、轉場中、轉場後的 `renderFrame`,貼給我
- [ ] 一次「復原」特效與關鍵影格一起消失;特效屬性裡能看到「進度」有關鍵影格,可手動拖曳調整
- [ ] 下層那一段不會被加上特效;重疊不足(只有一段)時顯示提示

## 3.19 自動排片(最近新增,優先看)

準備:時間軸音訊軌放一首歌、已分析節拍;素材庫放 3~5 支長度不同的影片(含一支很短的)和幾張圖片。節拍面板最下方「自動排片」。

- [ ] 選「每 4 拍」「最短 1 秒」→ 按「自動排片」:最上方多一條影片軌,片段首尾相接、一路排到歌曲結尾,切點落在橘色節拍標記上
- [ ] 影片沒有聲音(只聽到音樂);同一支素材不會連續出現;片段內容是素材的不同位置(不是每次都從頭)
- [ ] 圖片也會被抽進來,長度等於切段長度
- [ ] 取消勾選某些素材後再排,只會用到勾選的;很短的影片不會被拿來撐長的切段(若全部都太短,會顯示「素材太短、畫面有空隙」)
- [ ] 再按一次:換成另一組排法,**取代**上一次那條軌道(不會多出一條);「復原」一次回到按之前;重做又回來
- [ ] 一首 3 分鐘的歌「每 2 拍」:片段數不超過 150(超過會顯示提示);**播放與拖曳播放頭是否卡頓**。沒有代理檔時介面有黃字提示;建立代理檔後比較順
- [ ] 開 `window.__renderPerf = true` 播放排好的區段,把 `resolve`、`syncTextures`、`renderFrame`、`sceneRebuild` 貼給我(這項最容易卡);時間軸上百個片段時拖曳、縮放是否順
- [ ] 匯出一次:排片區段的畫面、聲音(只有音樂)和預覽一致

## 3.20 範圍匯出(最近新增,優先看)

- [ ] 匯出視窗展開「範圍」,勾選「只匯出一段」:預設終點是時間軸總長;按「用播放頭」可把起點 / 終點設成目前播放頭位置;下方顯示「實際範圍(已對齊影格)」與格數
- [ ] 起點大於等於終點、起點超過總長時,顯示紅字原因,「匯出」按鈕不能按

## 主控台:這些可以忽略

- `The powerPreference option is currently ignored when calling requestAdapter() on Windows`:Chrome 的警告
- `ort-wasm-simd-threaded...VerifyEachNodeIsAssignedToAnEp`:onnxruntime 說有幾個運算改在 CPU 上跑,只影響速度
- `Unable to determine content-length from response headers`:模型下載算不出總大小
- 沒有指定語言時的 `defaulting to English`:現在語言預設是中文,不應再出現

**不可忽略**:`No active project`、shader / WGSL 編譯錯誤、`RuntimeError`、`Uncaught (in promise)`。
