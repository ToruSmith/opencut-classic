# 實機驗收清單

CI 只能證明「程式能編譯、純邏輯的測試過了、shader 語法正確」。**畫面、聲音、效能、瀏覽器儲存**都沒有人在 CI 裡看過,
所以每次部署後,花 5 分鐘用真實瀏覽器走一遍。

## 準備(一次就好,存起來重複使用)

- 一支 10~20 秒、有人說話的影片(`talk.mp4`),最好是中文
- 一首短音樂(`music.mp3`)
- 一張圖片(`photo.jpg`)
- 一個綠幕短片(`green.mp4`,沒有可略過去背那項)
- 一個三則字幕的 `test.srt`

開啟網站後,按 F12 打開主控台,整個過程留著看。

## 1. 基本流程(每次都要做)

- [ ] 開啟網站,專案列表正常顯示,主控台沒有**新的**紅色錯誤
- [ ] 建立新專案,進入編輯器
- [ ] 「媒體」匯入 `talk.mp4`、`music.mp3`、`photo.jpg`,縮圖都出現
- [ ] 把影片拖進時間軸,預覽有畫面,按播放**有聲音**,畫面與聲音同步
- [ ] 拖動播放頭,預覽跟著更新,不會卡在同一格
- [ ] 分割、刪除片段,各做一次「復原」「重做」
- [ ] 重新整理頁面,再開同一個專案:內容、素材都還在

## 2. 效果(最近新增,優先看)

在「特效」分頁,把效果拖到影片上,調整屬性面板的滑桿,**預覽要即時變化**:

- [ ] 模糊
- [ ] 色彩調整、黑白、復古褐色、暗角
- [ ] **色溫與色調**:色溫往右畫面變暖、往左變冷;陰影、亮部、褪色有反應
- [ ] **暖色調 / 冷色調 / 底片褪色**:強度拉到 0 時畫面回到原樣
- [ ] **去背(綠幕)**:套在 `green.mp4` 上,綠色變透明,下層看得到;調「容許範圍」「邊緣柔化」邊緣有變化
- [ ] 同一個片段疊兩個效果,兩個都有作用
- [ ] 把效果刪掉,畫面恢復

> 任何一個 shader 壞掉,可能整個效果面板都沒反應(所有效果共用同一個管線)。如果全部效果一起失效,先看主控台。

## 3. 轉場與淡化(最近新增,優先看)

選取時間軸上的片段,到「轉場」分頁:

- [ ] 「淡入淡出」:影片開頭漸顯、結尾漸隱;**音量也跟著漸變**(戴耳機聽)
- [ ] 先把片段音量調成 −6 dB、不透明度調成 50%,再套淡入:淡入結束時應停在 −6 dB 和 50%,**不會跳回 0 dB / 100%**
- [ ] 進場:從左滑入、縮放進入、旋轉進入、彈出,各看一次
- [ ] 出場:切換到「片段結尾」,向右滑出、縮小退出,動畫結束時剛好是片段尾端
- [ ] 套用後在屬性面板或曲線編輯器看得到關鍵影格,可以微調
- [ ] 「復原」一次能撤銷整個轉場

## 3.5 新快捷鍵(最近新增,優先看)

- [ ] 時間軸有三四個片段時按 ↓ / ↑:播放頭一格一格跳到片段的頭尾;連按會一直往前/往後
- [ ] 選一個中間的片段按 Shift+Delete:片段消失,同軌後面的片段往前補上;Ctrl+Z 能完整還原
- [ ] 選片段按 Ctrl+X 再移動播放頭按 Ctrl+V:片段被搬到新位置
- [ ] 按 M:播放頭位置出現書籤,再按一次消失;有幾個書籤時按 Shift+↑ / Shift+↓ 會在書籤之間跳
- [ ] 按 = / -:時間軸放大、縮小
- [ ] 點一下右側屬性面板的滑桿後按 ↑ ↓:應該是調整滑桿,不是跳剪輯點
- [ ] 打開「鍵盤快速鍵」視窗:新項目都在,= 與 - 的標示正確(不是顯示成 +)

## 3.6 音訊淡化、交叉溶解、新濾鏡(最近新增,優先看)

- [ ] 時間軸上的音樂片段:滑過時左上 / 右上角出現白色圓點,往內拖曳出現三角形陰影與「淡入 x 秒」提示;放開後播放,開頭聲音漸大、結尾漸小
- [ ] 屬性面板「音訊」區有「淡入(秒)」「淡出(秒)」,改數字後時間軸的陰影同步變化;Ctrl+Z 能復原
- [ ] 有淡化的片段在中間按 S 分割:左半只剩淡入、右半只剩淡出,分割點沒有突然靜音
- [ ] 匯出一段有淡入淡出的影片,聽起來和預覽一致
- [ ] 把後一段影片拖到上方軌道、開頭和前一段重疊約 1 秒,選取其中一段 →「轉場」面板 →「交叉溶解」:重疊處畫面溶接、聲音交叉淡化;Ctrl+Z 一次就全部復原
- [ ] 效果面板有「銳利化」「發光」「分離色調」,套用後畫面有變化,拖動參數即時更新;匯出結果和預覽一致(發光範圍不會因為解析度不同而差很多)

## 3.7 版本紀錄、備份提醒、代理檔(最近新增,優先看)

- [ ] 編輯專案 10 分鐘以上(期間有修改)後回到專案列表,專案選單「版本紀錄」裡有一筆;按「還原」→「確定還原?」後內容回到那個版本,列表裡多了一筆「還原前」的版本
- [ ] 從編輯器用瀏覽器「上一頁」回到列表後還原,再打開專案,看到的是還原後的內容
- [ ] 專案選單「匯出備份」能下載 `.opencut-backup`;建立超過 7 天且沒備份的專案卡片上有「尚未備份」提示,備份後消失
- [ ] 素材面板對影片按右鍵「建立代理檔」:縮圖左下角顯示「代理 xx%」,完成後顯示「代理」;預覽拖曳時間軸明顯變順,畫面時間點和原本一致
- [ ] 建立代理檔途中按右鍵「取消建立代理檔」:進度消失,沒有錯誤
- [ ] 有代理檔的影片匯出:輸出是原始解析度(不是 1280)
- [ ] 右鍵「刪除代理檔」後預覽改回原始檔

## 4. 字幕與語音轉文字

「字幕」分頁:

- [ ] 「匯入」`test.srt`:時間軸最上方多一條文字軌,三則字幕在正確時間出現;`<i>` 這類標記不會出現在字幕文字裡
- [ ] 語言選「中文」,按「語音轉文字」:
  - [ ] 先顯示「載入模型 N%」(第一次要下載,需要連網)
  - [ ] 模型載完後**自動切換成「辨識中 N%」**,百分比會增加,不會卡在載入 100%
  - [ ] 辨識中「取消」按鈕可用,按下去能中止
  - [ ] 完成後產生字幕軌;每則字幕不超過約 12 個字、不重疊
  - [ ] 音樂或靜音段落沒有出現亂七八糟的字幕
- [ ] 產生的字幕(Whisper 多半輸出簡體)可以被選取、修改文字

## 5. 匯出

- [ ] 「匯出」→ MP4、預設品質、勾選「匯出時包含音訊」→ 完成後下載或存檔
- [ ] **用播放器打開匯出的檔案**:畫面有效果與轉場、聲音有、音畫同步、結尾沒被截掉
- [ ] 取消匯出一次,不會留下壞掉的檔案或讓介面卡住
- [ ] 取消勾選「包含音訊」再匯出,檔案沒有聲音

## 6. 備份與儲存

- [ ] 專案列表選單「匯出備份」,得到 `.opencut-backup` 檔
- [ ] 「匯入備份」該檔:出現名稱帶「(匯入)」的新專案,打開後內容與素材完整、可播放
- [ ] 「儲存空間」視窗顯示用量;開關「離線模式」正常

## 7. 結束前

- [ ] 主控台沒有**新的**紅色錯誤(見下方可忽略清單)
- [ ] 不同瀏覽器(例如 Chrome 與 Edge)至少各開一次

## 主控台:這些可以忽略

- `The powerPreference option is currently ignored when calling requestAdapter() on Windows`:Chrome 的警告
- `ort-wasm-simd-threaded...VerifyEachNodeIsAssignedToAnEp`:onnxruntime 說有幾個運算改在 CPU 上跑,只影響速度
- `Unable to determine content-length from response headers`:模型下載算不出總大小
- 沒有指定語言時的 `defaulting to English`:現在語言預設是中文,不應再出現

**不可忽略**:`No active project`、shader / WGSL 編譯錯誤、`RuntimeError`、`Uncaught (in promise)`。

## 發現問題時,把這些貼給我

1. 哪一項沒過、你做了什麼、預期什麼、實際看到什麼
2. 主控台的紅字(截圖或文字)
3. 預覽卡頓時:在主控台輸入 `window.__renderPerf = true`,播放幾秒,把印出的各階段耗時貼上
4. 瀏覽器與版本、作業系統
