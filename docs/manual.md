# 使用說明書

個人用的瀏覽器剪輯器。沒有帳號、沒有後端:素材與專案都存在你自己的瀏覽器(IndexedDB / OPFS),不會上傳。
這份說明書依「剪輯流程」整理;各功能的實機驗收步驟在 [`qa-checklist.md`](qa-checklist.md),實作細節在 `AGENTS.md`。

> 提醒:畫面、聲音、效能 CI 看不到。標「未實機驗證」的項目,請自行確認結果再使用。

## 1. 基本操作

- **專案列表**:建立 / 開啟 / 刪除專案。「清除空白專案」會刪掉沒有素材也沒有片段的專案;離開編輯器時空白專案也會自動丟掉。
- **匯入素材**:左側「媒體」匯入影片、音樂、圖片。素材留在瀏覽器裡,重新整理不會消失。
- **時間軸**:把素材拖進時間軸;可分割、刪除、移動,支援復原 / 重做。
- **組合片段**(像剪映的「創建組合」):框選多個片段(可跨多條軌道)→ 右鍵「建立組合片段」,它們會包成時間軸上的一個片段,位置與畫面不變;
  右鍵「開啟組合片段」(或在片段上連點兩下)進去編輯內容,工具列「返回」回到外層;「解除組合」還原成原本的片段。
  可跨軌道框選視訊 / 圖片 / 文字 / 音訊;**特效片段不能放進組合**,選取的片段之間夾著沒選的片段(會改變上下層順序)也會被拒絕並說明原因。
  組合內容是另一個「場景」(場景面板標示「組合片段」);被引用的場景無法刪除。未實機驗證,請見 `qa-checklist.md` 3.30。
- **總長度**:只由影片、音訊、圖片、文字等內容決定,單獨的特效片段不會撐長時間軸。
- **預覽**:播放時以音訊時鐘為準,畫面跟著聲音走;預覽解碼來不及時會先顯示上一格、暫停後補成精確的那一格。

## 2. 預覽吃力時

1. 到素材庫對該影片「建立代理檔」(0.5 秒一個關鍵影格、不含聲音)。代理檔只用於預覽,匯出一律用原始檔。
2. 切很多小段、又隨機排序時,代理檔幾乎是必要的。
3. 要量效能:在開發者工具主控台輸入 `window.__renderPerf = true`,每 60 格輸出一次各階段耗時。

## 3. 畫面效果

在左側「特效」面板把效果加到片段(或放在特效軌上影響下方所有畫面),再到屬性面板調整參數,參數可做關鍵影格。

| 類別 | 效果 |
|---|---|
| 基本 | 模糊、色彩調整、黑白、復古褐色、暗角、色溫與色調、暖色調 / 冷色調 / 底片褪色、去背(綠幕) |
| 風格化 | 馬賽克、色差、色調分離、底片顆粒 |
| 動態 | 畫面震動、放射模糊、故障、鏡像 |
| PV 畫面 | 網點、雙色調、VHS、集中線、波浪扭曲、漏光、魚眼 |
| LUT | 匯入 `.cube` 檔,或用內建風格(預設 teal-orange;「負片」最容易看出有沒有生效) |
| 擦除 | 線性、圓形光圈、時鐘、百葉窗、棋盤、菱形、噪點溶解、方塊崩落、對開 |

- **效果組合**:特效面板上方一鍵加入多層組合(衝擊、復古膠卷、電影感、賽博故障、夢幻柔光),一個復原步驟。
- LUT 存在專案裡(約 140 KB/個),目前沒有刪除介面。

## 4. 轉場

在「轉場」面板。

- **進出場動畫**:滑入、縮放、旋轉、彈出、淡化,套在單一片段上。
- **隨機轉場**:對選取的多個片段各抽一種進出場動畫,相鄰不重複。
- **切點轉場**(不需要重疊):閃白、縮放衝入、甩鏡、旋轉甩入、故障切、震動切、隨機。作用在同一軌道首尾相接的片段。
- **兩段之間**(要先讓兩段重疊):交叉溶解、推移、滑動擦除、縮放。
- **兩段之間的擦除**:用上面的擦除形狀做轉場,只處理畫面;聲音另用交叉溶解或音訊淡化。
- **緩慢推近 / 平移(Ken Burns)**:圖片的推近、拉遠、四向平移。

## 5. 聲音

屬性面板「音訊」分頁(影片原聲與音訊片段)。

- 音量、靜音、**淡入 / 淡出**(預覽、匯出、波形都會套用)。
- **標準化音量**:把選取的有聲片段各自調到同一響度(目標 -16 dB),選多個就能讓它們一樣大聲;有音量關鍵影格的片段會略過;一個復原步驟。
  用的是區塊均方值(非完整 LUFS),人聲與音樂這種差很多的素材,數字一樣不代表聽起來一樣大聲(未實機驗證)。
- 變速:屬性面板「速度」分頁;**變速曲線**(漸快 / 漸慢 / 子彈時間 / 中間衝刺)是階梯式近似,套用後各段靜音。
- **定格**:時間軸工具列「定格」按鈕,在播放頭處產生一段定格片段(預設 2 秒)。

## 6. 剪 AMV / 踩點

時間軸工具列的音符按鈕開啟「節拍」面板。

1. **分析節拍**:「重音」模式找鼓點(可調靈敏度與最短間隔),「節拍格」模式估計 BPM 後排出等距格線。結果寫成橘色的「節拍」書籤,時間軸會吸附;重新分析會取代舊的節拍書籤,手動書籤不受影響。
   只用合成節拍測過,真實音樂(節奏不穩、變速、純人聲)的準確度未驗證。
2. **依節拍分割**:對選取片段每 1 / 2 / 4 / 8 拍切一刀,可設最短片段。
3. **重排**:隨機打散或反轉選取的同軌道片段,首尾相接。
4. **一鍵快剪**:首尾相接 → 依節拍切 → 選擇性打散,一個復原步驟。
5. **節拍脈衝**:在選取的畫面片段上,每 1 / 2 / 4 拍瞬間放大再收回(輕 / 中 / 強);會取代該片段原有的縮放關鍵影格。
6. **自動排片**:依節拍從素材庫抽片段排滿整首歌(隨機抽、不連續重複)。評價「有點雞肋」,畫面和拍子關係不大。
7. 手動打標記:播放時按 `M` 加書籤。

## 7. 字幕與歌詞

左側「字幕」面板。

- **匯入**:SRT、LRC 歌詞檔。
- **點拍同步歌詞**:貼上歌詞,播放音樂時按空白鍵逐句打點(退格可退回),可設按鍵補償(預設 0.1 秒);完成後一次寫入文字軌,一個復原步驟。
- **卡拉 OK 填色**:選取字幕,高亮色由左向右蓋過底色(均勻速度;旋轉文字退回整個畫面寬)。
- **匯出字幕**:SRT 或 LRC;有選取文字片段時只匯出選取的。
- 自動轉錄字幕會依標點與字數(12 字)切段。

## 8. 匯出

- 匯出視窗可選品質與格式;**範圍**可只輸出時間軸上的一段(起迄秒數對齊影格,檔名帶範圍後綴)。
- 音訊分段混音並套限幅器(天花板 0.98),長專案不會一次吃光記憶體。
- 網頁自動驗收只驗過 webm;mp4 / AAC 路徑需要你在真實瀏覽器上確認。

## 9. 備份與保護

- **版本紀錄**:專案選單可還原先前的版本(只存專案 JSON、不含素材;還原前會先存一份目前狀態)。
- **備份 / 匯入**:可選擇「只存專案」或連素材一起;只存專案的備份匯入後,用「重新連結」依檔名與大小對回素材,Chromium 可選整個資料夾掃描。
- 刪除素材後可以復原;刪掉的大檔案要到下次開啟專案才會真正釋放空間。

## 10. 已知限制

- 沒有 WebGPU 的瀏覽器會退回 WebGL 後備;兩者都沒有就無法預覽與匯出。
- 變速曲線是階梯式,接縫處聲音會跳;段數多時預覽吃力。
- 遮罩參數不能做關鍵影格。
- 組合片段:沒有自己的屬性面板(不能對整個組合套特效 / 變速);解除組合後內容場景仍會留在場景面板,需手動刪除。
- 文字遮罩吸附有一個已知失敗的測試。
- 重專案(多圖層、多特效、大量切點)的效能還沒量過;若卡頓,請在該專案用 `window.__renderPerf = true` 取數據。
